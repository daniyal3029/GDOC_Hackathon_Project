# GDOC_Hackathon_Project
## Introduction
This repository contains the source code for the GDOC Hackathon Project, a meeting intelligence platform.
## Getting Started
To get started with the project, please refer to the individual README files in the founder-brain-backend and founder-brain-frontend directories.
## Directory Structure
The repository is divided into two main directories: founder-brain-backend and founder-brain-frontend. The backend directory contains the server-side code, while the frontend directory contains the client-side code.

## Usage Examples
* To start the backend server, navigate to the founder-brain-backend directory and run `npm run dev`.
* To start the frontend development server, navigate to the founder-brain-frontend directory and run `npm run dev`.
## Project Description
The GDOC Hackathon Project is a meeting intelligence platform designed to provide a comprehensive solution for meeting management and analytics. It aims to improve the efficiency and productivity of meetings by providing features such as automated meeting summaries, action item tracking, and meeting analytics.
## Installation
To install the project dependencies, run `npm install` in the root directory of the project, then navigate to the founder-brain-backend and founder-brain-frontend directories and run `npm install` in each.
